**Creación de un kit para el usuario o usuaria**

Se creará un kit dentro de un usuario particular, no una tarjeta. 
Para ello, sigue estos pasos:

1. Envía una solicitud para crear un nuevo usuario con el token de autenticación (authToken).
2. Envía una solicitud para crear un kit personal para este usuario. 
3. Asegúrate de pasar también el encabezado Autorization.
